# Design System: Galley Desk

## Overview

Документ первоначально составлен 2026-09-27; описание повторно сверено с кодом PR #6 на 2026-10-28. Пользователь подтвердил сохранение интерфейса и перенос его правил в сестринские проекты. Новая визуальная концепция, метафора или палитра не вводятся. Сентябрьские снимки и computed styles ниже — исторические свидетельства, а не изображения текущей сборки. Текущие результаты функциональных проверок: [протокол](../../docs/verification.md).

Интерфейс организован вокруг чтения: книжная типографика в центре, компактные инструменты по краям, спокойные сплошные поверхности. Иерархию создают шрифт, тон поверхности, отступы и состояние элемента. Тень отделяет временный слой от рабочего пространства; постоянно видимый текст не помещён в отдельную карточку.

**Key Characteristics:**

- Независимые настройки типографики книги и интерфейса.
- Общая тема окна, панелей, редактора и всплывающих слоёв.
- Плоская область чтения без рамки, скругления, тени и размытия.
- Компактные действия с контурными иконками, подписями для доступности и тематическими подсказками.
- Сохранение места чтения, выделения и черновиков при работе с инструментами.

Frontmatter фиксирует используемые значения для документирования и инструментов DESIGN.md. `light-*` и `dark-*` — имена записей этого документа, не новые CSS-переменные. Они представляют две базовые темы; остальные темы разрешаются через общий пакет. В версии 0.17.0 каталог содержит 17 тем, включая добавленные пары Edda и Thoth. При изменении реализации обновлять этот снимок, а не использовать его как второй runtime-каталог.

Sidecar содержит расширения схемы и десять визуальных образцов; они наследуют переменные хоста с fallback на базовую светлую тему. Шрифты берутся из окружения предпросмотра; без локального Geist используется fallback. Два порога раскладки в sidecar вычисляются JavaScript, а не являются CSS media queries. Синтетические цветовые ramps и новый Creative North Star не добавлены: пользователь запросил фиксацию существующих правил.

Исторический экспорт всех 13 тем версии 0.15.0, computed styles и изображения находятся в [свидетельствах](../../docs/reviews/evidence/design-system-2026-09-27/README.md). [Порядок переноса](../../docs/design-system-transfer.md) описывает применение к другому проекту без навязывания ему модели рецензирования.

## Colors

### Primary

Акцент интерфейса — `--desk-accent`, ссылающийся на `--app-focus`. Он обозначает клавиатурный фокус, активный разделитель и обычные правки. В базовой светлой теме это приглушённый синий, в тёмной — более светлый голубой. Основная кнопка открытия книги использует тон hover-поверхности, а не сплошную акцентную заливку.

### Neutral

| CSS-переменная | Применение |
|---|---|
| `--app-bg` | Основной фон окна и центральной области чтения |
| `--app-panel` | Строка окна, боковые панели, меню, подсказки, попапы и диалоги |
| `--app-panel-muted` | Поля ввода, подложка переключателя видов, встроенные карточки рецензии |
| `--app-text` | Текст интерфейса |
| `--app-text-muted` | Подписи панелей, путь/имя файла, вторичные сведения, счётчики |
| `--app-hover` | Hover, выбранные кнопки и активная глава; разделители строк диагностики |
| `--app-error-text` | Ошибки, недоступные записи, опасные/закрывающие действия |
| `--desk-warning` | Внешнее изменение файла: отдельная светлая/тёмная пара |

Светлая базовая тема сочетает тёплый фон бумаги с почти белыми панелями; тёмная — угольно-зелёную область чтения с синевато-чёрными панелями. Состав цветов определяется выбранной темой, а не одной обязательной бренд-палитрой.

**The Shared Theme Rule.** Один результат `themeToCssVariables(theme)` применяется на корневой контейнер; `colorScheme` и `data-scheme` соответствуют выбранной теме. «Системная» (`auto`) следует за сменой схемы ОС без перезапуска. Явно выбранная тема имеет приоритет над ОС. Неизвестный идентификатор разрешается в базовую тему текущей системной схемы.

### Цвета редактора и рецензии

Текст редактора использует `--ge-color-text`, а интерфейс — `--app-text`: эти значения в базовых темах немного различаются. Markdown использует отдельные семантические токены ссылок, выделения, кода, цитат, таблиц и синтаксиса из того же каталога. Каретка наследует текущий цвет текста. Вложенный `[data-theme]` редактора получает `inherit` для переданных `--ge-color-*`, `--ge-shadow-editor`, `--ge-content-padding`, чтобы базовая CSS-тема редактора не перекрыла выбор приложения. Полный перечень — блок `review-editor > [data-theme]` в `app.css`.

Цвета сигналов имеют две пары по **схеме выбранной темы**, а не по названию палитры и не по схеме ОС. Их значения представлены в frontmatter (`signal-*`, `comparison-*`, `edit-tint-*`, `deletion-*`).

| Смысл | Цветовой характер | Обозначение |
|---|---|---|
| Заметка | Синий / светло-синий | `IconMessage` в выборе типа |
| Требуется правка | Красный / светло-красный | `IconPencil` в выборе типа |
| Предупреждение | Охристый / светло-жёлтый | `IconAlertTriangle` |
| На проверку | Фиолетовый / светло-фиолетовый | `IconEye` |
| Обычная правка | Акцент текущей темы | Карандаш; нейтральная подложка диапазона |
| Чистое удаление | Отдельный красный | Маркер удаления, когда текста диапазона уже нет |
| Сравнение | Парные красная/зелёная подложки | `<del>` с зачёркиванием / `<ins>` без подчёркивания |

В списке рецензии сигналы обозначаются `IconBolt` с цветом типа и текстовым названием. Не заменять названия одним цветом.

В «Тексте» сигнал подчёркивает нижнюю часть строки градиентом: прозрачность до 66%, затем 24% цвета сигнала через `color-mix(in srgb, …, transparent)`. В «Сравнении» используется 16% подложка и цветное пунктирное подчёркивание. Выбранный тип сигнала в карточке — 15% подложка; заданный `borderColor` при общей `border: 0` не создаёт видимой рамки. Поисковая находка — 35% акцента и радиус 2px; это отдельная декорация, не выделение редактора.

Красная заливка кнопки закрытия системного окна (`window-close-hover`) — локальное исключение. `--app-border`, `--app-tab-text`, `--app-error-bg`, `--app-error-border` и `--app-backdrop` существуют в каталоге, но не становятся обязательной обводкой/плашкой каждого элемента Desk.

## Typography

Две роли, два независимых масштаба: `ui` — Geist с системным sans-serif fallback; `book` — Literata с Georgia/serif fallback. Размеры frontmatter — значения по умолчанию. Пользователь меняет UI в пределах 10–24px, книгу — 10–48px; ширина строки задаётся отдельно. Формы, кнопки и select наследуют шрифт интерфейса. Шрифты включены в сборку, normal/italic, `font-display: swap`; Geist — variable 100–900, Literata — 200–900, включая кириллицу.

**The Two Type Scales Rule.** Изменение шрифта книги не меняет меню, подсказки и карточки. Изменение UI-размера не подменяет размер текста книги. В CSS используются `--desk-ui-font`, `--desk-ui-size`, `--desk-book-font`, `--desk-book-size`, а в редактор дополнительно передаются `--ge-font-body` и `--ge-font-size`.

| Роль | Реализованное правило |
|---|---|
| Обычный UI | Роль `ui`; общий UI line-height явно не задан — браузерный `normal` |
| Название на стартовом экране | 0.88em, 500, одна строка с ellipsis |
| Название открытой книги | 1.1em, 600; путь ниже — 0.8em; общий line-height 1.2 |
| Заголовок боковой панели | 0.9em, 500, muted |
| Название главы над текстом | 0.9em, 400, muted; имя файла под ним — 0.75em |
| Название недавней книги | 600; путь — 0.9em, muted |
| Заголовок диалога | 1.2em; нативный bold заголовка сохраняется |
| Тип сигнала в списке | 0.8em, 600, line-height 1.35; «Было»/«Стало» обозначены иконками с доступными названиями |
| Фрагмент записи | До трёх строк, line-height 1.35; пустой фрагмент — italic muted |
| Подсказка | UI-шрифт, line-height 1.4; shortcut отдельной строкой 0.85em |
| Карточка метаданных / preview исходного текста | UI-шрифт, line-height 1.5 |
| Текст, сравнение и исходник | Роль `book`, line-height 1.8; исходник также книжным шрифтом |
| YAML в редакторе метаданных | `ui-monospace, monospace` |
| Комментарий сигнала в тексте | 0.85 от UI-размера, line-height 1.5 |

Заголовки **внутри Markdown** принадлежат Galley Editor: h1–h6 — соответственно 2 / 1.5 / 1.25 / 1.1 / 1 / 0.9em, вес 700; leading 1.2 / 1.3 / 1.4 / 1.4 / 1.4 / 1.4. h6 приглушён. Inline code использует mono-стек редактора, 0.9em, радиус 3px, padding `0.125em 0.25em`. Не переносить эту иерархию на заголовки оболочки.

## Layout

### Окно и область чтения

Desktop-окно по умолчанию 1200×850, минимальное 720×520 ([window.ts](src/main/window.ts)). Это ограничения Desk, не универсальные размеры всех продуктов. Корень занимает 100vh, использует flex-column и ограничивает overflow; содержимое и панели скроллятся независимо. Сжимаемые flex/grid-дети получают `min-width: 0` / `min-height: 0`.

Строка окна — 44px. Рабочее пространство: оглавление / разделитель / текст / разделитель / рецензия. Предпочтительные ширины панелей — 315 и 336px, границы каждой 240–560px, разделитель 6px. Центр получает `minmax(0, 1fr)`; расчёт раскладки резервирует для него 480px.

| Доступная ширина рабочего пространства | Автоматическая раскладка |
|---|---|
| ≥972px | Обе панели; при нехватке места их ширины пропорционально уменьшаются до минимума |
| 726–971px | Оглавление остаётся, рецензия свёрнута |
| <726px | Обе панели свёрнуты |

Это пороги, выведенные из `fitLayout`, а не media queries. Отдельное CSS-правило `max-width: 1099px` уменьшает padding центральной области с `24px 28px 0` до `20px 16px 0`, панелей с `14px 12px` до `12px 8px`, переносит прямые действия Zen и диагностики в меню книги.

У текста, сравнения и исходника общая ширина `min(100%, lineWidth)`; значение по умолчанию 700px, допустимо 320–1600px. Это ширина контейнера, **не гарантированные 700px печатной строки**: внутри редактора остаются gutter, scrollbar и padding. В базовых темах padding контента Galley — `42px 28px`; Desk заменяет нижний padding на 80px. У исходника/сравнения нижний запас 48px. Между заголовком главы, поиском и основным содержимым — gap 16px.

Скрытая по ширине панель открывается поверх текста: отступы top/bottom/side 8px, ширина `min(336px, calc(100% - 32px))`, padding-top содержимого 44px под кнопку закрытия. При достаточной ширине кнопки панелей переключают их видимость в раскладке. Пользовательское предпочтение ширины не перезаписывается только из-за сужения окна.

### Плотность и отступы

Единой формальной шкалы spacing в коде нет. Frontmatter именует повторяющиеся фактические шаги, но не объявляет обязательную сетку кратности. В частности, 5/7/9px тоже реально используются. Основные интервалы: 2px в переключателях и списке рецензии, 4px в тулбаре и группе действий поиска, 8px между полем поиска и действиями, 6–8px между компактными действиями, 10–12px в формах и карточках, 16px между блоками, 20–24px у крупных поверхностей.

### Zen

Панели скрываются, текст сохраняет ограниченную ширину и центрируется. Основные действия тулбара скрыты; **строка окна, название книги, кнопка «Выйти из Zen», оконные действия и доступная на этой ширине диагностика остаются**. Метаданные главы и маркеры рецензии доступны. `Ctrl/Cmd+Alt+Z` переключает режим; Escape закрывает слои, но не выключает Zen. При переключении нельзя терять черновики и место чтения.

## Elevation & Depth

Постоянные поверхности разделяются тоном. Центральный текст и gutter прозрачны, без рамок и теней. Временные меню, popover, flyout, tooltip, всплывающие панели и диалоги используют общий `--app-dialog-shadow`; значения двух базовых тем находятся в [sidecar](.impeccable/design.json), остальных — в каталоге тем. Встроенная карточка рецензии получает muted-поверхность без обязательной тени. Нативные диалоги используют собственный backdrop `rgb(0 0 0 / .35)`, а не токен `--app-backdrop`.

**The Floating Layer Rule.** Тень отделяет временный инструмент от текста; оболочка самого текста остаётся плоской. Не возвращать Galley Editor его самостоятельную карточку с рамкой/тенью/размытием поверх оформления Desk.

| Слой | Реализованный z-index |
|---|---:|
| Разделитель панелей | 3 |
| Кнопки открытия свёрнутых панелей | 30 |
| Flyout сигнала | 35 |
| Всплывающая карточка записи | 40 |
| Боковая панель поверх текста | 42 |
| Кнопка метаданных / центр уведомлений | 43 |
| Оформление | 44 |
| Меню книги | 45 |
| Меню главы / popover метаданных | 50 |
| Общая подсказка | 100 |
| Модальный `dialog.showModal()` | Нативный top layer, не соревнование z-index |

Это текущий порядок, а не произвольный масштаб для новых компонентов. Меню главы и метаданные порталятся внутрь тематического корня через `AnchoredLayer`, обходя clipping родителей. Положение пересчитывается при resize/scroll; горизонтальный запас 8px, начало ниже якоря на 6px, высота ограничена окном. Flyout и карточка записи имеют собственные правила позиционирования; не считать их автоматически эквивалентными `AnchoredLayer`.

Движение минимально: линия разделителя и кнопки flyout имеют `background-color 120ms ease` в CSS оболочки. Задержка подсказки 300ms и сохранение клавиатурного ресайза через 250ms — тайминги поведения, не декоративная анимация. Общая система анимаций и специальная ветка reduced-motion в оболочке не заданы.

Обычные кнопки и поля без рамок. Фокус — `2px solid var(--desk-accent)` с offset 2px. У активного CodeMirror внешняя outline отключена; не переносить это исключение на кнопки и поля. У кнопок типов сигнала задан `borderColor`, но общей рамки нет; не восстанавливать её на основании одного inline-свойства. Длинные фрагменты и сообщения используют переносы `overflow-wrap: anywhere`; названия глав/файлов в навигации — ellipsis.

## Components

### Кнопки и иконки

Базовая кнопка: inline-flex, центрирование, gap 7px, padding `7px 9px`, прозрачный фон. Hover и `aria-pressed=true` получают `--app-hover`. Disabled — opacity 0.4 и обычный курсор; отдельная блокировка hover для disabled в текущем CSS не задана. Кнопка открытия книги — hover-поверхность и padding `10px 22px`. Опасные действия используют цвет ошибки. Специального глобального стиля `:active` нет.

Контурные иконки — `@tabler/icons-react`, базово 18×18px, stroke-width 2. В строке окна — 16px, в инструментах глав — 17px. Общий CSS `.app-root svg` имеет приоритет над простым SVG-атрибутом `size` из компонента: при переносе учитывать **вычисленный** размер, а не только JSX. У иконок-действий есть доступное название и тематическая подсказка. Логотип — существующий SVG Galley Desk, 23×23px в строке окна; это бренд конкретного приложения, не общая иконка семейства.

### Поля и оформление

Input/select/textarea: muted-поверхность, padding `8px 10px`, UI-шрифт, стандартный focus-visible. Textarea занимает всю ширину, resize vertical. Панель оформления — две колонки `1fr 1fr`, gap 12px; тема, шрифт/размер UI, шрифт/размер книги, ширина строки. Ширина панели `min(440px, 100vw - 28px)`, padding `40px 20px 20px`, высота не больше `100vh - 60px`, вертикальный скролл. Ошибки сохранения показываются текстом с `role=alert`.

### Навигация и панели

Оглавление: фильтр над списком, активная строка с hover-поверхностью, заголовок и имя файла, кнопка контекстного меню. Кнопка меню видна на hover, keyboard focus, активной главе и открытом меню. Padding кнопки главы `9px 4px 9px 10px`. Меню главы шириной 220px, padding 5px; пункты выровнены влево, padding 9px. Меню книги — 210px, padding 5px, пункты 10px. Переключатель видов — muted-подложка, padding/gap 2px; выбранность через `aria-pressed`.

Разделители доступны как `role=separator` с текущим/минимальным/максимальным значениями. Перетаскивание использует pointer capture; Escape отменяет текущий drag. Стрелки изменяют ширину шагом 16px, Home/End выбирают пределы, двойной щелчок возвращает исходную ширину. При перетаскивании выделение текста отключено.

### Подсказки

Один `TooltipHost` обслуживает React-кнопки и DOM-виджеты редактора через общий контроллер. Padding `6px 10px`, max-width `min(320px, 100vw - 16px)`, line-height 1.4. Shortcut ниже текста, margin-top 2px. Появление через 300ms на hover, сразу на focus; скрытие на mouseleave, blur, scroll и Escape. Отступ от окна 8px; если снизу нет места, tooltip переносится над триггером.

Host не перехватывает указатель (`pointer-events:none`) и не участвует в перетаскивании окна. `role=tooltip` и `aria-describedby` связывают подсказку с триггером; прежние чужие описания сохраняются. Не добавляется фокусируемая обёртка вокруг disabled-кнопки. `describe=false` позволяет не дублировать совпадающее accessible name. Интерактивный preview исходного текста — отдельный компонент, а не обычная подсказка.

### Диалоги и метаданные

Диалог действия: ширина `min(460px, 100vw - 32px)`, max-height `100vh - 32px`, padding 20px. Диагностика — такая же геометрия, но 440px; её диалог и кнопки явно используют `-webkit-app-region: no-drag`. Заголовок и крестик в одной строке, gap 12px; действия справа, gap 8px, у диагностики допускается перенос. `dialog.showModal()` обеспечивает модальность; закрытие возвращает фокус к вызывающему действию.

Метаданные: ширина `min(560px, 100vw - 32px)`, padding 18px, max-height `100vh - 80px` дополнительно ограничивается позиционированием. В форме gap 10px, у label 6px; YAML textarea не ниже 11rem. Подтверждение отказа от черновика накрывает сам popover поверхностью панели, а не всей страницы.

### Рецензия и текстовые отметки

Список рецензии показывает фиксированную иконку 18px и фрагменты изменения либо тип сигнала и комментарий. «Было»/«Стало» обозначены компактными иконками с доступными названиями вместо текстовой колонки. Фрагменты ограничены тремя строками; строки flex с gap 5px и line-height 1.35. Статус недоступной записи виден текстом, вся запись имеет opacity 0.65. Встроенные карточки используют muted-фон; заметка главы раскрывается локально.

Карточка записи: ширина 440px, padding 0.75rem, gap 0.5rem, радиус поверхности; max-width `min(100%, 100vw - 16px)`, прокрутка длинного содержимого, textarea от 8rem. Плавающая версия получает тень и запас от краёв 8px. Flyout у выделения — горизонтальный ряд из четырёх типов, gap/padding 4px. Его появление не забирает фокус; mousedown кнопки сохраняет выделение; Tab открывает клавиатурный путь к действиям.

Gutter прозрачен, без границы, фиксированной ширины 32px. Маркеры одной строки перекрываются со сдвигом 3px; hover и focus-within разворачивают их с шагом 24px поверх текста, не расширяя gutter. Отдельная запись — кнопка 24×24px с padding 3px; маркеры не превращают всё поле в одну большую цель. Placeholder удаления — 18×14px. Комментарий сигнала под текстом имеет max-height `min(12rem, 30vh)` и скролл. Preview «было» использует padding `12px 16px`, ширину не больше `min(420px, 80vw)`; **эффективные** поздние CSS-правила включают pointer-events и прокрутку с max-height `min(24rem, 60vh)`.

### Поиск, сохранение и восстановление фокуса

Поиск занимает строку над текстом, flex-wrap, gap 8px и горизонтальные отступы 12px. Поле растёт от basis 12rem, минимум 8rem; счётчик приглушён. Счётчик, стрелки и закрытие образуют неделимую группу с gap 4px. Переход к находке не забирает фокус из поля и не открывает flyout. Пустой запрос снимает подсветку. Состояние «сохранено» сжато до muted-точки, остальные состояния показывают текст; ошибка — error, внешние изменения — warning.

Escape закрывает подходящий открытый слой, а не все одновременно. Нативные диалоги, метаданные, меню главы, заметка главы и активный ресайз обрабатывают его сами. Порядок workspace: боковой overlay → popup → flyout → карточка → меню книги → оформление → поиск → preview. Поиск с фокусом сначала очищает запрос. Возврат к редактору должен сохранять его выделение; отсутствие размонтирования при смене оформления защищает IME и позицию чтения.

### Уведомления книги

[NoticeCenter](src/renderer/ui/Notice.tsx) размещает рабочие ошибки и предложения снизу по центру поверх книги, не меняя размеры редактора. Ширина `min(640px, calc(100% - 32px))`, нижний отступ не меньше 20px, gap 8px, z-index 43. При ширине до 759px нижний отступ увеличивается до 56px, чтобы оставить доступ к кнопкам панелей. Контейнер пропускает указатель, карточки принимают события; автоматического исчезновения нет.

Карточка использует panel-фон, общую тень, радиус 10px, padding `12px 14px`, gap 10px и UI line-height 1.5. Ошибки, предупреждения и информация различаются иконкой и текстом. Локальные ошибки форм остаются в форме. Предложение добавить найденные главы открывает диалог выбора; файлы не добавляются автоматически.

### Стартовый экран и рамка окна

Стартовый экран центрирован с безопасным overflow, padding 24px, gap 12px. Список недавних книг шириной `min(700px, 90vw)`, gap 6px; строка с panel-фоном, padding 12px, gap 16px, действия справа. Тема применяется уже на этом экране.

В открытой книге titlebar центрирует название и индикатор сохранения, а ниже показывает кнопку папки с каноническим путём. При ширине до 899px текст пути скрыт, но полный путь остаётся в подсказке и доступном описании. Кнопка папки использует иконку 13px. Titlebar: gap 9px, padding-left 12px; на macOS 82px под нативные traffic lights (`hiddenInset`, координаты 14/13px в main). На Linux собственные оконные кнопки шириной 46px на всю высоту строки. Только фон строки является drag-region; кнопки и поля — no-drag. Двойной щелчок фона переключает maximize на Linux. Поведение macOS здесь описано по коду, текущая визуальная проверка выполнена только на Linux.

Аварийный экран `ErrorBoundary` — отдельное исключение: он заменяет дерево `App`, располагает сообщение по центру, padding 32px, gap 12px, заголовок 1.1em и кнопку перезапуска. Ссылки на `--app-panel`/`--app-text` там не гарантируют наследование темы, поскольку тематический корень уже размонтирован; не использовать этот fallback как образец общей панели.

## Do's and Don'ts

### Do:

- **Do** применять тему на весь корневой контейнер, включая порталы и первый экран.
- **Do** сохранять независимые настройки книги и интерфейса и локальную поставку шрифтов.
- **Do** переносить состояния, клавиатурное управление и работу фокуса вместе с внешним видом.
- **Do** проверять светлую/тёмную темы, пользовательский UI-размер, длинные русские названия и сужение окна.
- **Do** переиспользовать опубликованные общие пакеты и явно согласовывать обновление их версий.
- **Do** брать значения из действующего CSS с учётом каскада и сверять с computed styles.

### Don't:

- **Don't** добавлять самостоятельную карточку, рамку, тень или blur вокруг текста книги при переносе оформления Desk.
- **Don't** подменять выбранную тему системной схемой внутри редактора или отдельного popover.
- **Don't** копировать временные абсолютные пути книг, название приложения, Electron IPC или модель рецензирования в общий дизайн-контракт.
- **Don't** считать наличие токена в каталоге требованием использовать его в каждом компоненте.
- **Don't** объявлять несуществующую строгую spacing-сетку, единую систему анимаций или проверенное соответствие WCAG.
- **Don't** переносить устаревшие комментарии вместо фактического поведения: Zen сохраняет строку окна, preview прокручивается.

### Зафиксированные исключения, не новые правила

В `app.css` подпись sort-preview ссылается на `--app-muted`, которого нет в текущем экспорте темы; это не новый семантический токен. У metadata-trigger z-index 43, а у sidebar-overlay 42: на узком снимке возможен визуальный конфликт у кнопки закрытия. Эти особенности зафиксированы как ограничения текущей реализации, не исправлялись и не должны становиться шаблоном для сестринских проектов. Диаграмма слоёв и документация описывают наблюдаемый код, а не заявляют отсутствие дефектов.
