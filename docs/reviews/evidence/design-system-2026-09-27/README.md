## Метод

Свежая Forge-сборка запущена через Playwright Electron в отдельном Xvfb/Openbox. Переменные `XAUTHORITY`, `WAYLAND_DISPLAY`, `XDG_SESSION_TYPE` сняты; `ELECTRON_OZONE_PLATFORM_HINT=x11`. Использована временная русскоязычная книга из двух глав и отдельный профиль приложения. Одна правка создана обычным вводом; после закрытия приложения исходный Markdown побайтно совпал с начальным содержимым (SHA-256 `283c980e4279e2d240c586983eebfeecfbcc7bf2428e17d72cb5e3d9233cc0d8`). Временная книга и профиль удалены.

Вставка «На рассвете.» сделана перед Markdown-заголовком намеренно как тестовый ввод: видимое `#` на снимке — содержимое исправленного текста этой пробы, не оформление заголовков.

- [computed-styles.json](computed-styles.json) — измерения ключевых элементов в каждом состоянии.
- [theme-catalog.json](theme-catalog.json) — полный снимок `themeToCssVariables` всех 13 тем; справочное свидетельство версии, не второй runtime-источник.
- [source-hashes.json](source-hashes.json) — ревизия и хеши исходников оформления для проверки свежести.

## Границы проверки

Сборка и сценарий съёмки завершились успешно. Проверена неизменность исходного Markdown. Это одна серия визуальной сверки, не полный прогон функциональных тестов. Поведение недемонстрированных состояний описано по коду. macOS, полный accessibility-аудит, все темы вживую и предельные размеры шрифтов: **NOT RUN**. Каталог всех тем выгружен программно.

При первоначальной съёмке применялся отдельный Xvfb/Openbox-wrapper. Старый capture-скрипт не перенесён: он содержит устаревшие селекторы и пишет результаты прямо в эту историческую папку. Для новой съёмки используйте текущий `scripts/gui-test.sh` и новую папку свидетельств. Исторические JSON и PNG не перегенерированы.
