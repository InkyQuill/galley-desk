# Перенос оформления Galley Desk

Рабочая ветка: `codex/desk-visual-redesign`, база `b11908f`.

## Объём

Направление взято из `packages/desk-prototype` и спецификации Claude. По уточнению пользователя центральная область и редактор имеют общий фон, без отдельной карточки. Меняется настоящее приложение с действующими командами и сохранением. Прототип, Pocket Editor, Galley Pad и пользовательские материалы не редактируются.

- Компактная шапка с Tabler Icons, поиск по Ctrl/Cmd+F, меню редких действий.
- Отдельные шрифты и размеры интерфейса и книги; локальные Geist/Literata с кириллицей; сохранение прежних настроек.
- Тематические поверхности, полноценная палитра встроенного редактора, ширина по умолчанию 700px.
- Цветные компактные строки рецензии; отдельные кнопки на полях, мягкая заливка правок и цветная полоса сигналов; пассивный просмотр оригинала по курсору и наведению.

## Технические решения

Существующий production CSS сохранён: Tailwind является инструментом прототипа, а отдельная миграция движка для этого оформления не нужна. Если позже потребуется общий utility-слой, его перенос останется самостоятельной работой.

Новые глобальные токены пока не добавляются: попапы используют существующий dialogShadow, UI-акцент — локальный алиас focus. Для независимого акцента во всех темах позднее потребуется расширение общего пакета. У колонки текста тень отсутствует по прямому запросу.

Кастомная рамка ОС и упаковка иконки остаются отдельными задачами, как в исходной спецификации. Нативная проверка macOS не заявляется.

## Исправленные регрессии

Независимое ревью оболочки обнаружило светлую палитру внутри явно тёмного редактора и Escape на кнопках поиска; оба дефекта исправлены. Проверены сохранение старых настроек, кириллица, реальный курсор, поиск и меню.

Проверки маркеров обнаружили потерю нативного выделения при восстановлении фокуса из попапа. Исправление сверяет фактическое DOM-выделение с сохранённым состоянием CodeMirror и восстанавливает его только при несовпадении. Отдельно устранено повторное появление пассивного предпросмотра после закрытия карточки: два Escape по-прежнему закрывают карточку и выходят из Zen.

Цвет карандаша теперь общий для полей и панели. Финальное интеграционное ревью дополнительно обнаружило, что пассивный предпросмотр не наследует пользовательскую типографику интерфейса. Исправлено в `1f75a5e`; проверено реальное применение Georgia 18px в предпросмотре при отдельном размере книги 20px. Повторное ревью одобрено, открытых замечаний нет.

## Среда проверки

Linux, локально распакованный Xvfb, один Electron worker. Системные пакеты не устанавливались. Виртуальный экран изолирует тестовый ввод от работающего пользователя; тесты и снимки выполнялись последовательно. Параллельные Electron-окна воспроизводимо перехватывали фокус, поэтому конфигурация теперь задаёт `workers: 1` по умолчанию.

При раннем прогоне на общем физическом экране один сценарий внешнего изменения получил посторонний ввод; тот же неизменённый сценарий прошёл 3/3 на изолированном экране. Сырые данные постороннего ввода не включены в evidence.

## Воспроизведение

После `npm run package`, на выделенном X-сервере (подставить его DISPLAY):

```sh
npm test
npm run typecheck
GALLEY_PACKAGED_EXECUTABLE="$PWD/apps/desktop/out/Galley Desk-linux-x64/Galley Desk" npm run test:desktop -- --workers=1
GALLEY_PERF=1 npx playwright test tests/desktop/performance.spec.ts --workers=1
```

В текущей CachyOS-среде для изолированного запуска использованы `DISPLAY=:1`, `GTK_MODULES=colorreload-gtk-module:appmenu-gtk-module`, удалены `XAUTHORITY`, `WAYLAND_DISPLAY`, `NO_COLOR`, `FORCE_COLOR` из окружения команды. Это условия данного стенда, а не требования формата книги или постоянная настройка приложения.

Нативная macOS, системная IME, кастомная рамка и упаковка иконки этим этапом не проверяются. Kotlin/Android suites не повторялись: формат и Pocket не изменялись; пройдены существующие E2E возврата папки из Pocket. DOM latency измеряет обновление DOM, не физическую отрисовку или fsync.
