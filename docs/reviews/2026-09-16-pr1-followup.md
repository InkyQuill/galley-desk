# PR #1: CodeRabbit и CI

## Исходный результат

Linux/macOS завершились на typecheck прототипа: React 19 изменил nullable RefObject. Contracts прошёл. По запросу пользователя пакет `packages/desk-prototype` удалён вместе с TypeScript reference и записями lockfile; исторические документы сохранены. Принудительный `tsc -b --force` прошёл.

## Разбор CodeRabbit

- 4028626182: upload-artifact закреплён на проверенном SHA v4.6.2; setup-node также закреплён на SHA v4.4.0.
- 4028626211: UI_FONT_SIZE_BOUNDS общий для main и renderer; 12 проверок настроек/оформления прошли.
- 4028626194: защита исходного frontmatter переведена на исходные байты и отображение координат; тесты воспроизводят скрытый разделитель, CRLF и BOM.
- 4028626203: ошибка recents после завершённой операции журналируется отдельно; возвращается уже сохранённая книга.
- 4028626214: записи публикуются только из принятой ревизии, включая смену темы. Electron воспроизвёл старую подсветку при новом тексте; регрессия исправлена.
- 4028626223: общей блокировки не добавляем. Сервис выставляет managing до await, дожидается сохранений, блокирует команды и открытие глав; добавляемые файлы отсутствуют в spine и не имеют живой сессии. Обычная запись сохраняет chapter_id. Реален внешний процесс, меняющий sidecar во время подготовки: добавляется оптимистическая повторная проверка входных файлов. Она сокращает окно, но не гарантирует атомарность с несотрудничающим внешним процессом.

## Дополнительные сообщения

Biome не разобрал некавыченные URL шрифтов. URL заключены в кавычки без изменения ресурсов. Предупреждение CodeRabbit о 80% docstring coverage не является контрактом проекта; шаблонные комментарии ради процента не добавляем.

`npm audit` после удаления прототипа: 29 находок (3 low, 1 moderate, 24 high, 1 critical). Critical находится в транзитивном tar инструментов; npm не предлагает совместимого автоматического исправления. Прежнее ограничение `security.md` сохраняется; принудительная замена major-версий не включена в исправление ревью.

## macOS: второй прогон

После удаления прототипа CI обнаружил 14 отказов unit-тестов на канонических путях временных папок. Они воспроизведены на Linux с TMPDIR-симлинком, вместе с пятью новыми storage-тестами. Исправлены фикстуры и явная канонизация аргумента теста forgetRecent; контракт приложения не ослаблен. 116 affected-тестов под тем же TMPDIR прошли. Изменение `f56eebd`, helper service-тестов входит в коммит логики.

## Linux: второй прогон

60 Electron прошли, 7 отказов. Шесть packaged-тестов отказали при запуске: Ubuntu runner требует корректных root/4755 прав chrome-sandbox. Workflow настраивает штатный sandbox и сохраняет failure artifacts; sandbox не отключается. Седьмой тест ошибочно ожидал подстроку «кот» после Undo, хотя она присутствовала в «кот!», и начинал внешнюю запись раньше завершения операции. Ожидание исправлено: точный документ и сохранённая рецензия.

Полное чтение документа при публикации маркеров заменено проверкой ожидающей синхронизации. Сохранены диагностические JSON обеих сборок.

Шесть тестов собранного приложения прошли с принудительным SUID sandbox. Тест управления переведён на общий bounded launcher; ENOENT во время ожидания создания файла повторяется, другие ошибки сохраняются. Первичные ссылки, команды воспроизведения и ограничения установочного пути — в release runbook.

Дополнительно уточнены ожидания завершённого переключения главы, закрытия, появления sidecar, обновления рендера после дисковой записи и детерминированного отказа сохранения заметки.
