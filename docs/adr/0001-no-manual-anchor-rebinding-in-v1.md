# В v1 нет ручного перепривязывания

Galley Desk и Pocket Editor сохраняют недоступные правки и сигналы и показывают их в списке рецензии с причиной. Пользователь может прочитать сохранённый текст, удалить запись и при необходимости создать новую; выбирать новый диапазон для существующей записи нельзя.

После внешнего изменения используется общий алгоритм Pocket Editor: проверка `selection_sha256` по сохранённому тексту, проверка диапазона при совпадении `source_sha256`, иначе поиск точных вхождений с уточнением по prefix/suffix. Это не fuzzy matching. Собственное применение правки использует известное преобразование координат, а не повторный поиск текста.

Недоступность записи не делает весь документ некорректным. Старые числовые диапазоны могут пересекаться с диапазонами другой версии исходника. Проверка пересечений переносится из общего отказа чтения/записи на разрешённые активные диапазоны: все пересекающиеся правки помечаются конфликтующими и не участвуют в отображаемом исправленном тексте и применении. Сигналы могут пересекаться. Остальные записи работают и сохраняются.

Для этого в рамках Galley Desk дорабатываются сериализация, валидация мутаций, проекция и UI Pocket Editor. JSON-форма v1 не меняется; совместимость проверяется с обновлённым выпуском Pocket Editor. Старые версии могут отвергать документы с пересекающимися сохранёнными диапазонами.

Статус вычисляется по текущей версии исходника. В v1 нет постоянного флага потерянной привязки: при последующем открытии единственное точное совпадение может разрешиться в другом месте. Не добавляем скрытые флаги и фиктивные хеши. Если практика потребует другого алгоритма, меняем его совместно в обоих приложениях.

Ручное перепривязывание отложено из-за дополнительной сложности интерфейса, особенно на телефоне. Это не основание отвергать всю рецензию или удалять запись автоматически.
