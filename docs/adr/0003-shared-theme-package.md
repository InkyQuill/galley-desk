# Темы выделяются в общий пакет `@inkyquill/galley-themes`

Galley Desk использует палитры и структуру токенов Galley Pad (`src/themes/tokens.ts`, `catalog.ts`) как основу. Значения и типы выделяются в публикуемый пакет `@inkyquill/galley-themes`, пригодный для разных потребителей Galley Editor. Код приложения Galley Pad не становится зависимостью Galley Desk.

Пакет живёт в репозитории `/home/inky/Development/editors/galley-editor` рядом с редактором: `packages/galley-editor` и `packages/galley-themes`. Темы версионируются совместно с редактором. Перенос сохраняет публичные импорты существующего редактора и требует проверки публикации обоих пакетов.

Galley Pad переводится на общий пакет в рамках этой работы, с проверкой светлой/тёмной темы и настройки шрифтов. Galley Pad остаётся отдельным приложением. Предварительная работа в репозиториях Galley Editor и Galley Pad выполняется до интеграции общего пакета в Galley Desk.

Цвета типов сигналов Pocket Editor остаются семантикой Galley Desk, наложенной на общую тему; универсальный пакет не получает знания о сигналах и рецензиях.
