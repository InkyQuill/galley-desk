# Galley Editor остаётся универсальной библиотекой

`@inkyquill/galley-editor` — отдельная публикуемая библиотека для нескольких приложений. В рамках Galley Desk разрешены и ожидаются изменения Galley Editor, Galley Pad и Pocket Editor. Общие исправления ввода, рендеринга, команд и публичного API вносятся в Galley Editor и проверяются также в Galley Pad.

Разделение координат:

- Galley Editor отвечает за экранное представление, позиции в своём Markdown-документе (UTF-16) и транзакции. Существующий `getSelection()` уже возвращает позиции документа, а не пиксели.
- Galley Desk сопоставляет производный текст с канонической главой и хранит происхождение фрагментов.
- Форматный модуль Galley Desk переводит позиции канонической главы в UTF-8 bytes и создаёт anchors Pocket Editor.

Сначала проверяем существующие возможности библиотеки; добавляем только недостающий общий API. Знания о правках, сигналах и формате Pocket Editor остаются в Galley Desk за адаптером, а не превращаются в специальные случаи внутри Galley Editor.

Для проверки неопубликованных изменений используются собранные локальные npm-архивы; CI совместной интеграции может собирать их из зафиксированных ревизий. Обычные сборки используют опубликованные фиксированные версии и lockfile. Абсолютные пути локального разработчика в релизные зависимости не попадают.
