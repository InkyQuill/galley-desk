# Руководство пользователя Galley Desk

Galley Desk — настольное приложение для рецензирования Markdown-книг
(Linux и macOS). Вы открываете папку книги, читаете и правите текст; каждое
изменение сохраняется как правка или сигнал в sidecar-файле формата Pocket
Editor рядом с файлом главы. Исходный Markdown при этом не меняется, пока
правка не применена явно.

## Запуск

```bash
npm ci        # один раз в корне репозитория
npm start     # режим разработки (Electron Forge)
```

Собранное приложение: `npm run package`, результат — `apps/desktop/out/`
(запускается исполняемый файл `Galley Desk`, а не dev-сервер).

## Открытие книги

- **Открыть папку…** — выбрать папку с главами (`.md` в верхнем уровне).
  Если манифеста `.pocket-editor.json` ещё нет, он создаётся автоматически.
- **Недавние** — повторное открытие возвращает книгу, последнюю главу и
  прокрутку (в том числе после перезапуска приложения).
- **Закрыть книгу** — дожидается завершения всех сохранений. После закрытия
  папку можно передавать дальше (см. «Передача папки»).

## Виды главы

- **Текст** — редактор Galley с маркерами записей (карандаш правки, молния
  сигнала, подложки диапазонов).
- **Сравнение** — read-only источник, где каждая активная правка показана
  парой «удалено → введено», сигналы — подложкой и молнией. Здесь же кнопки
  «Отменить/Повторить применение» (отдельный стек применений).
- **Исходник** — немаркированный raw Markdown, только чтение.

## Поиск по главе

Поле поиска над текстом главы. Область поиска зависит от вида и показана
рядом с полем:

- **Текст** и **Сравнение** ищут по тексту главы (производный текст,
  который видит редактор);
- **Исходник** ищет по raw Markdown (например, найдёт разметку `# `).

Поиск — точная подстрока, без регулярок и без учёта регистра. **Комментарии
записей и заметка главы в поиск не входят.** Стрелки (или Enter/Shift+Enter)
переходят по совпадениям, счётчик показывает «текущее/всего»; результаты
пересчитываются при каждом обновлении главы. В «Сравнении» переход к
совпадению во введённой части правки прокручивает именно её.

## Оглавление

Поле **Фильтр глав** скрывает несовпадающие названия. Фильтр меняет только
отображение — манифест книги не изменяется.

## Рецензия

Правая панель: список записей главы и заметка главы.

- Клик по записи — переход к якорю и карточка с действиями.
- **Правка**: «Применить» переносит изменение в Markdown-файл (только в
  ручную, по одной), «Отклонить» удаляет запись из sidecar.
- **Сигнал**: комментарий и тип (`note`, `change_required`, `warning`,
  `review`). Создание: выделить текст в «Тексте», в flyout выбрать тип.
- Заметка главы сохраняется в поле `chapter_note` sidecar.

### Недоступные и конфликтующие записи

Запись может потерять якорь: текст главы изменился снаружи, совпадение
неоднозначно или правка пересекается с другой. Такие записи показываются с
причиной:

- «недоступна» с причиной (`stale` — текст изменился, `ambiguous` — несколько
  кандидатов); сохранённые тексты видны, применять нельзя;
- «конфликтует» — пересечение с другой правкой.

Недоступную запись можно только удалить или оставить; приложение не
угадывает, куда она «на самом деле» указывала. Перепривязки якорей вручную
нет (см. ADR 0001).

### Session Undo

Отмена действует внутри сессии главы: **Ctrl+Z / Ctrl+Shift+Z** (Cmd на
macOS) отменяют и повторяют ввод текста, пачка набора — один шаг. Отменённый
ввод остаётся частью сессии, пока глава открыта. Кнопки «Отменить/Повторить
применение» в «Сравнении» — отдельный стек для применённых правок. При
закрытии книги истории сбрасываются; применённые правки и записи остаются.

### Ошибки записи и внешние изменения

- Если сохранить не удалось, заголовок показывает **«Ошибка сохранения»** и
  кнопку **«Перечитать главу»**: локальный текст сохранён, автоматического
  затирания нет — выбор за вами.
- Если файл главы изменён снаружи, глава помечается **«Внешнее изменение»**.
  Варианты: **«Открыть внешнюю версию»** (внешний текст становится рабочей
  базой) или **«Экспортировать черновик…»** (локальный черновик сохраняется
  в отдельный JSON). Ввод блокируется до явного выбора.

## Режим Zen

Кнопка **«Режим Zen»** скрывает верхнюю панель, оглавление и панель рецензии.
Выход — постоянная кнопка **«Выйти из Zen»** в правом верхнем углу или
**Escape**: сначала закрывается открытый popup/flyout/карточка, повторный
Escape выходит из Zen.

## Оформление

Кнопка **«Оформление»**: тема (встроенный каталог Galley, «Системная»
следует за схемой ОС), шрифт, размер шрифта (10–48) и ширина строки
(320–1600). Значения хранятся в настройках приложения (appData) и **никогда
не записываются в файлы книги**. Цвета сигналов и правок остаются
Pocket-совместимыми при любой теме.

## Передача папки после завершённого сохранения

Когда книга закрыта (или приложение вышло без ошибки сохранения), папка
полностью готова для передачи в Pocket Editor или другому человеку:

- главы — исходные `.md`-файлы; применённые правки уже внутри них;
- неприменённые правки, сигналы и заметка главы — в sidecar-файлах
  `<глава>.review.json` (формат Pocket Editor);
- манифест `.pocket-editor.json` описывает состав книги.

Открывать ту же папку в двух приложениях одновременно не стоит: Galley Desk
замечает внешние изменения и не переписывает чужие файлы молча, но
одновременная запись — всегда риск.

## Ограничения

- Ручные привязки якорей отсутствуют (ADR 0001).
- Подпись и нотаризация сборок macOS пока не выполняются — нет учётных
  данных (см. `docs/runbooks/release.md`).
- Ручные проверки IME, буфера обмена и нативных диалогов на macOS
  документированы как непроверенные (см. `docs/verification.md`).
