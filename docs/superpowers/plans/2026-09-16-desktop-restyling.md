# Перенос оформления в рабочий Galley Desk

Основание: спецификация Claude 2026-09-16, готовый desk-prototype и запрос пользователя на перенос в приложение. Поправка пользователя: редактор не выделяется отдельным фоном.

## Global Constraints

- Работа в настоящем Electron-приложении, существующий IPC и сохранение сохраняются.
- Центральная область и текст имеют общий фон: без карточки, рамки, скругления и тени вокруг редактора. Боковые панели отделены мягким тоном; чтение по центру, пользовательская ширина сохраняется.
- Tabler Icons, русские доступные имена действий, существующие темы и Pocket-цвета сигналов. UI Geist / книга Literata с локально поставляемыми шрифтами и системными fallback; независимые настройки, миграция старых настроек без потери значений. Дефолт ширины 700px.
- Сохраняются реальные ошибки/внешние изменения, Undo, выбор главы, позиция, исходник read-only и порядок Escape. Фокус не крадётся у печатающего пользователя.
- Не менять Pocket/Pad, существующий прототип и чужие незакоммиченные материалы. Настоящая кастомная рамка и упаковка иконки остаются отдельным этапом по исходной спецификации.
- Использовать существующий CSS и токены, без обязательной миграции production на Tailwind; это инструмент прототипа, а не требование поведения. Тень только попапам, существующий dialogShadow достаточен; акцент UI пока из focus с явным локальным алиасом.

## Task 1: Оболочка, оформление и панели

Перенести язык прототипа в production renderer: спокойная полноразмерная область чтения; компактные боковые панели; иконки поиска, видов, Zen; меню редких действий; скрываемый поиск с клавиатурным доступом. Строки рецензии: цветные карандаш/молния, ellipsis, полное доступное имя, статус в карточке. Попапы/заметка/оформление согласованы по токенам. Развести UI/book шрифты в shared type, main settings, renderer. Поставлять шрифты локально. Сохранить старые параметры при чтении. Проверки миграции и поведения; адаптировать e2e только под намеренно изменённый UX.

## Task 2: Разметка рецензии в редакторе

Полевой gutter с отдельной кликабельной иконкой на каждую запись, несколько на строке в порядке позиции. Никаких inline-иконок и комментариев между строками. В тексте правка — только after и мягкая заливка; сигнал — нижняя треть строки маркером цвета типа без подчёркивания. Удаление доступно через gutter. Before в общем flyout по курсору или наведению; клавиатурная работа и текущие попапы сохраняются. Геометрия обновляется при вводе/прокрутке/resize; применять CM6 extension в Desk, не менять общий редактор без выявленной необходимости. Проверить реальные e2e Markdown/ввод/маркеры и тему.

## Приёмка

- Typecheck, unit, package и Electron e2e; новые проверки UI и регрессий по изменениям поведения.
- Снимки реального окна со светлой и тёмной темой, проверка компактного окна и Zen.
- Независимое ревью каждого этапа и итогового diff. Нативный macOS здесь не заявляется проверенным.
- Без push и публикации.
